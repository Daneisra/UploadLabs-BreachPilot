First public release of **Smart Automation**, a hacking quality-of-life mod for Upload Labs. *Première publication publique de Smart Automation, mod de confort pour le hacking d'Upload Labs.*

Unofficial mod, not affiliated with EnigmaDev Studios. *Mod non officiel, sans lien avec EnigmaDev Studios.*

## English

- **Auto Threat Manager** (off by default):
  - Keeps each Breach node on the threat level that pays most per minute for your objective (XP, data, intel or balanced), elite levels included.
  - Climbs once to unlock the next level, then comes back.
  - Three profiles. Pause and Resume on each node, emergency stop on `Ctrl+Alt+F10`.
- **Smart Hacking Advisor** (read-only, `Ctrl+Alt+F8` or the `Conseil` button):
  - Shows the best wiring first, with the estimated gain, drawbacks and reliability, then the recommended purchase.
  - Lists things to try on your chain. Detailed figures fold away.
- Works from the attacks it observes, so unknown nodes and nodes from other mods do not get in the way. Writes nothing into your saves.
- **Changes since 0.5.0:**
  - A look-alike node from another mod is left alone.
  - Profitability is measured again when the chain changes.
  - The panel no longer fails on an empty resource name.
  - Bilingual README and archive checks.

**Install:** copy `Daneisra-SmartAutomation-0.5.1.zip`, without extracting it, into the `mods` folder next to `Upload Labs.exe`. To turn the regulation on, set `regulation_mode` to `active`, for example with ModManager. See the README for details and known limitations. The in-game interface is in French for now.

**Tested on:** Upload Labs 3.0.12, Godot Mod Loader 7.0.1, Windows.

## Français

- **Auto Threat Manager** (désactivé par défaut) :
  - Garde chaque nœud d'infiltration sur le niveau qui rapporte le plus par minute pour votre objectif (XP, données, renseignements ou équilibré), niveaux élites compris.
  - Monte une fois pour débloquer le niveau suivant, puis revient.
  - Trois profils. Pause et Reprendre sur chaque nœud, arrêt d'urgence `Ctrl+Alt+F10`.
- **Smart Hacking Advisor** (lecture seule, `Ctrl+Alt+F8` ou bouton `Conseil`) :
  - Affiche d'abord le meilleur branchement, avec le gain estimé, les inconvénients et la fiabilité, puis l'achat conseillé.
  - Propose des pistes à essayer sur votre chaîne. Le détail des calculs est repliable.
- S'appuie sur les attaques observées, donc les nœuds inconnus ou venus d'autres mods ne gênent pas. N'écrit rien dans vos sauvegardes.
- **Depuis la 0.5.0 :**
  - Un nœud d'un autre mod qui ressemble à une cible est écarté.
  - La rentabilité est remesurée quand la chaîne change.
  - Le panneau ne plante plus sur un nom de ressource vide.
  - README bilingue et vérification de l'archive.

**Installation :** copiez `Daneisra-SmartAutomation-0.5.1.zip`, sans le décompresser, dans le dossier `mods` à côté de `Upload Labs.exe`. Pour activer la régulation, mettez `regulation_mode` sur `active`, par exemple avec ModManager. Le README détaille les options et les limites connues.

**Testé sur :** Upload Labs 3.0.12, Godot Mod Loader 7.0.1, Windows.
